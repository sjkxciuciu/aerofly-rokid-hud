# 2.6 自动跑道版教程

[返回下载首页](../README.md) · [English](TUTORIAL-2.6.en.md)

## 安装与升级

1. 从首页下载名称含 **2.6-AutoRunway-Bilingual** 的完整 ZIP 并解压。不要使用原始 2.6 旧整包。
2. 退出游戏。按 Windows + R，输入 `shell:Personal` 打开文档目录；建立 `Aerofly FS 4\external_dll`，将新版 **AeroflyRokidHud.dll、AeroflyRokidRunways.dat** 一起放入。不要放到 Steam 游戏目录。
3. 安装中文或英文 APK，二选一覆盖。ADB 示例：
   `adb install -r AeroflyRokidHud-2.6-AutoRunway-Chinese.apk`
   英文改用 English 文件。设备显示 unauthorized 时先在眼镜确认 USB 调试授权。两种语言同应用 ID，不可并存。
4. CMD 和 PS1 留在同一解压目录，双击 **Set-ReferenceRunway.cmd**。
5. 点击 **Automatic runway selection**，明确启用自动模式。不要根据开发说明里“本机已经启用”判断你的电脑已配置。
6. 电脑和眼镜连接可互通的局域网，重新启动游戏进入飞行，打开 HUD。

旧 DLL 不支持完整自动跑道功能；仅替换 APK 不够。APK 为调试签名，其他签名构建可能无法覆盖；不要直接卸载而不考虑现有应用数据。

## 使用

轻触镜腿切换仪表 → 地图 → 3° 下滑参考；地图前后滑动缩放。在线底图需要互联网，仪表和自动选跑道不需要互联网。

飞机在入口前约 0.1–20 NM、真航向差不超过 45° 且接近延长线时寻找候选；候选稳定约 3 秒才显示，8 NM 内接近中线时锁定。缺少新数据、明显偏离或更换机场时清除或重新选择。查看显示的机场/跑道名称，平行跑道尤其需要核对。

这是几何匹配，不跟随 FMS，也不是 ATC 许可。数据库不是所有机场的完整覆盖，可能与游戏景物有差异。

## 手动指定 / 关闭 / 恢复自动

打开 CMD，填写以下信息，点击 **Save / Enable** 切换手动模式：

| 字段 | 输入 |
| --- | --- |
| Runway name | 1–24 个英文字母、数字、空格、/ 或 - |
| Threshold latitude | 着陆入口纬度，十进制度，北正南负 |
| Threshold longitude | 同一入口经度，十进制度，东正西负 |
| Threshold elevation | 入口标高，ft MSL，不是飞机高度 |
| Landing direction | 从着陆入口沿跑道的真航向，0–360°，不是磁航向 |

使用游戏场景对应入口，不是机场中心；不要按跑道编号猜真航向。小数用英文句点。配置保存在文档下 `Aerofly FS 4\external_dll\AeroflyRokidApproach.ini`。

**Automatic runway selection** 恢复自动；**Disable reference** 关闭。设置工具提示约 1 秒读取；查看 HUD 状态确认。安装或更换 DLL 则必须退出并重启游戏。

## 常见问题

| 问题 | 检查 |
| --- | --- |
| CMD 找不到脚本 | 完整解压，CMD 与 PS1 同目录 |
| 缺少数据库 | DAT 与新版 DLL 一起放在 external_dll |
| 参考一直不可用 | 自动模式是否启用、DAT、数据新鲜度、进近区域、候选稳定时间 |
| 选错平行跑道 | 核对名称；切换手动模式指定正确入口 |
| 寻找电脑 | 游戏重启、DLL 位置、同网互通、防火墙及访客隔离 |
| 底图缺失但仪表正常 | 检查眼镜互联网访问；底图和局域网仪表是不同连接 |

电脑接收 UDP 49003，眼镜接收 UDP 49002。不要关闭整个防火墙或全局降低脚本执行策略；遵守受管理电脑的规则。

## 读数与验证范围

参考固定假设 3°、入口上方 50 ft，使用气压高度，应设置正确 QNH。正垂直偏差表示飞机高于参考，菱形在中线下方；距离沿跑道延长线计算，不是 DME 斜距。无效或过期数据不应当作可用引导。

不是 ILS、没有地形或障碍物保护，仅供模拟游戏。G 值缺失显示不可用，不代表 0 G。

作者确认的是历史 2.5 实机验证。新版自动跑道功能的开发记录为本地测试，尚未实机验证，不能把历史验证扩展到所有新功能、固件或机型。
